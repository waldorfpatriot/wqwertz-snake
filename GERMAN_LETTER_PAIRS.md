# Catalogue of Important German Letter Pairs

This catalogue treats a "letter pair" as a German bigram: two adjacent
letters inside normal written words. The core ranking below is based on the
German bigram chart in `ressources/diagramme-triagramme.pdf`, figure 4
("Die haeufigsten Bigramme im Deutschen"). Percentages are approximate shares
of all adjacent letter pairs in the source chart.

## Practice Tiers

### Tier 1: Core Fluency

Start with the seven highest-frequency pairs:

`er`, `en`, `ch`, `de`, `ei`, `nd`, `te`

These cover articles, endings, high-frequency function words, and highly
recognizable German spelling patterns.

### Tier 2: German Shape

Add the pairs that make words feel specifically German:

`ie`, `ge`, `un`, `st`, `be`, `ng`, `sc`

This tier teaches the `ge-` prefix, `un-` prefix, `-ung` ending, `sch` entry
motion, and common consonant clusters.

### Tier 3: Expansion

Round out with the remaining frequent pairs:

`in`, `es`, `ne`, `re`, `he`, `an`, `se`, `di`

These are useful for longer practice strings and for balancing left/right hand
movement on QWERTZ.

## Supplemental German Spelling Pairs

These pairs are not part of the top-22 chart above, but they are valuable in a
typing curriculum because they represent common German spelling patterns:

| Pair | Role | Example words |
| :--- | --- | --- |
| `au` | Common vowel pair. | `auch`, `Haus`, `laufen` |
| `eu` | Common vowel pair. | `neu`, `heute`, `Leute` |
| `äu` | Umlaut variant of `au`/`eu` sound patterns. | `Häuser`, `läuft`, `träumen` |
| `sp` | Common initial consonant cluster. | `Spiel`, `sprechen`, `spät` |
| `ck` | Common spelling after short vowels. | `backen`, `Ecke`, `drücken` |
| `ss` | Common double consonant and `ß` alternative in some contexts. | `Wasser`, `wissen`, `muss` |
| `tz` | Common affricate spelling. | `jetzt`, `Platz`, `setzen` |
| `ll` | Common double consonant. | `alle`, `sollen`, `schnell` |
| `mm` | Common double consonant. | `kommen`, `immer`, `stimmen` |
| `nn` | Common double consonant. | `dann`, `kann`, `rennen` |
