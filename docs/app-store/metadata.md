App Review notes:

qwertZnake is an iPad typing-training game for the German QWERTZ keyboard layout. It does not require sign-in, does not show ads, and stores gameplay statistics locally on the device. For best testing, use the on-screen QWERTZ keyboard at the bottom of the app or connect an external keyboard. Press Space to start/pause and use the highlighted T, B, F, and J keys to control the game.

Practice QWERTZ touch typing through Snake challenges built for short, focused student training sessions.

Description:

qwertZnake turns touch typing practice into a game. Control Snake with focused QWERTZ keys while learning finger positions, accuracy, and keyboard confidence.

Built for students, classrooms, and self-guided practice, qwertZnake focuses on the German QWERTZ layout. Color-coded keys show which finger belongs to each area, while the game keeps each session active and easy to repeat.

Features:
- QWERTZ touch typing practice through gameplay
- Color-coded finger zones for both hands
- Accuracy, score, and WPM feedback
- Board-size settings and local practice levels
- Local leaderboards on device
- No account required
- No ads, tracking, or internet connection required

qwertZnake works best with an external or connected keyboard. On iPad, the app also includes a color-coded on-screen keyboard for practice and review.
